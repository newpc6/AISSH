# AI SSH 用户指南

## 快速开始

### 首次启动

1. 下载并安装 AI SSH
2. 启动应用后，设置登录密码
3. 在设置中配置 AI 提供商（OpenAI、Ollama 或自定义端点）
4. 开始添加服务器并使用 AI 辅助功能

### 添加服务器

1. 点击左侧面板的 `+` 按钮
2. 填写服务器信息：
   - 名称：为服务器起一个易于识别的名字
   - 分组：选择或创建分组
   - 地址：服务器 IP 或域名
   - 端口：SSH 端口（默认 22）
   - 用户名：登录用户名
   - 认证方式：密码或 SSH 密钥
3. 点击保存

### 连接服务器

- **方法 1**：双击服务器列表中的服务器
- **方法 2**：选中服务器后点击会话栏的 `+` 按钮
- **方法 3**：点击服务器卡片右上角菜单中的"连接"

## 功能详解

### 1. SSH 会话管理

#### 会话标签
- 每个会话以标签页形式显示
- 标签上的圆点表示连接状态：
  - 🟢 绿色：已连接
  - 🟡 黄色：连接中
  - 🔴 红色：已断开
  - ⚪ 灰色：空闲

#### 会话操作
- **重连**：点击终端头部的"重连"按钮
- **关闭**：点击标签上的 `×` 按钮
- **切换**：点击标签或使用快捷键

### 2. AI 助手

#### AI 模式
- **审核模式**：AI 生成命令后需要人工确认
- **自动模式**：AI 自动执行多步骤任务

#### 使用 AI
1. 在右侧 AI 面板输入问题或任务
2. AI 会根据终端上下文提供建议
3. 在审核模式下，检查命令后点击"执行"
4. 在自动模式下，AI 会自动执行整个流程

#### AI 命令预测
- 在终端输入时，AI 会预测下一个命令
- 按 `Tab` 键接受预测
- 继续输入忽略预测

#### 终端选中文本加入 AI
1. 在终端中选中文本
2. 点击"加入 AI"按钮
3. 文本会自动添加到 AI 输入框

### 3. 文件管理

#### 文件浏览
- 点击左侧"文件"标签切换到文件模式
- 支持路径输入直接跳转
- 双击目录进入
- 右键文件可下载或预览

#### 文件传输
- **上传**：点击"上传"按钮或拖拽文件到面板
- **下载**：右键文件选择"下载"
- **编辑**：双击文本文件可在线编辑

#### 路径跟踪
- 勾选"跟踪终端路径"
- 文件面板会自动跟随终端当前目录

### 4. 服务器监控

#### 实时指标
- CPU 使用率及趋势图
- 内存使用情况
- 磁盘空间
- 网络带宽

#### 图表操作
- 鼠标悬停查看详细数据
- 点击放大图标查看大图
- 在设置中调整刷新频率

### 5. 命令历史与收藏

#### 命令历史
- 自动记录所有执行的命令
- 支持搜索和过滤
- 点击命令可快速复制或执行

#### 收藏命令
- 点击命令旁的星星图标收藏
- 收藏的命令会保存在"收藏"标签
- 支持排序和分组

### 6. 服务器分组管理

#### 创建分组
1. 点击左侧"分组"按钮
2. 点击"新增分组"
3. 输入分组名称并保存

#### 管理分组
- 重命名：直接修改分组名称
- 删除：删除未被使用的分组
- 排序：拖动分组调整顺序

### 7. 批量操作

#### 批量模式
1. 在服务器列表中选择多个服务器
2. 输入统一的任务描述
3. AI 会为每台服务器生成并执行命令

#### 适用场景
- 批量部署应用
- 统一配置更新
- 批量日志收集
- 统一健康检查

## 设置说明

### 通用设置
- **健康检查间隔**：检测服务器连接状态的频率
- **终端行数**：每个会话保留的历史行数
- **界面布局**：调整面板宽度和高度

### 安全设置
- **桌面登录**：启动时是否需要密码
- **网页访问**：是否允许浏览器访问
- **密码修改**：更改登录密码

### AI 设置
- **AI 提供商**：选择 OpenAI、Ollama 或自定义
- **API 端点**：设置 AI 服务地址
- **模型选择**：选择使用的模型
- **系统提示词**：自定义 AI 行为
- **上下文长度**：AI 可参考的终端历史长度
- **预测数量**：AI 预测的命令数量

### 指标设置
- **刷新间隔**：服务器指标更新频率
- **图表时间范围**：趋势图显示的时间跨度
- **数据点数量**：图表上的数据点数量

## 高级功能

### 自定义系统提示词

在 AI 设置中，可以自定义系统提示词来调整 AI 行为：

```
你是一个专业的 Linux 系统管理员助手。
- 优先使用安全的命令
- 对危险操作给出警告
- 提供详细的命令解释
```

勾选"覆盖默认系统提示词"后，自定义提示词将完全替代内置提示词。

### Agent 模式配置

对于复杂任务，可以在设置中调整 Agent 参数：

- **最大 Token 数**：AI 单次响应的最大长度
- **上下文限制**：AI 可参考的最大上下文
- **步数限制**：Agent 自动执行的最大步数
- **超时设置**：命令执行的超时时间

### 导入导出

#### 导出服务器列表
1. 点击"文件" → "导出服务器列表"
2. 选择是否包含加密凭据
3. 保存 JSON 文件

#### 导入服务器列表
1. 点击"文件" → "导入服务器列表"
2. 选择之前导出的 JSON 文件
3. 确认导入

#### 导出软件配置
- 导出所有设置和偏好
- 方便在不同电脑间同步配置

## 故障排除

### 连接问题

**问题**：无法连接到服务器
**解决**：
1. 检查服务器地址和端口
2. 确认用户名和密码/密钥正确
3. 检查网络连接
4. 查看运行日志（工具 → 日志）

### AI 问题

**问题**：AI 无响应或报错
**解决**：
1. 检查 AI 提供商设置
2. 确认 API Key 正确
3. 检查网络连接到 AI 服务
4. 查看 AI 错误日志

### 性能问题

**问题**：应用运行缓慢
**解决**：
1. 减少终端保留行数
2. 降低指标刷新频率
3. 关闭不需要的会话
4. 检查系统资源占用

## 最佳实践

### 安全建议
1. 使用 SSH 密钥认证而非密码
2. 定期更换登录密码
3. 不要在公共网络启用网页访问
4. 导出配置时谨慎处理加密凭据

### 效率提升
1. 善用命令收藏功能
2. 配置常用 AI 提示词
3. 使用批量模式处理重复任务
4. 利用快捷键提高操作速度

### AI 使用技巧
1. 提供清晰的任务描述
2. 在审核模式下检查危险命令
3. 利用终端上下文让 AI 更好理解
4. 自定义系统提示词优化 AI 行为
